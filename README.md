# ShoeVista

A full-stack footwear web application.

## Features
- About Us page with routing
- Reusable product data (Top Brands & Best Sellers)
- Frontend-backend integration
- Responsive UI

## Tech Stack
- React (Vite)
- Node.js / Express

## How to run

### Frontend
npm install
npm run dev

### Backend
npm install
node server.js
